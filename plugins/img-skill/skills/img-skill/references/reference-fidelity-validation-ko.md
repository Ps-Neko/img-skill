# 참고 이미지 충실도 내부 관찰 기록

평가일: 2026-08-28
대상: `img-skill`의 참고 이미지 변환 규칙

## 이 기록의 지위

이 문서는 세 번의 **비블라인드·각 1회 생성**에서 보인 결과를 추적하기 위한 내부 관찰 기록이다. 통제된 벤치마크, 계정 전체에 대한 대표 표본, 모델 성능 보증이 아니다. 현재 스킬의 적응형 평가 규칙은 [quality-check.md](quality-check.md)를 따른다. 아래 종합점수는 당시 고정 루브릭으로 계산한 역사적 참고값이며 현재의 필수 통과 조건을 대신하지 않는다.

## 관찰된 일치와 차이

- 세 결과에서 피사체 정체성, 포즈, 시점과 핵심 관계는 대체로 보존됐다.
- 실사 영역과 재구성 영역을 나누는 큰 구조, 종이 섬유·절단면 또는 수채 투명층의 디자인 계열은 재현됐다.
- 제목이 목표보다 커지고 비대칭 여백이 줄어드는 경향이 있었다.
- 한 종이공예 결과에서는 source의 QR 형태와 무관한 장식이 변형 영역으로 옮겨졌다.
- 자동차 결과에서는 목표의 세 구조 단계가 네 단계로 늘어났다.

이 차이 관찰이 현재 규칙의 이미지 역할 분리, preserve/transform/ignore 목록, 단일 기하 계약, 우연한 QR·문자 제외, 정확한 이산 개수 통제로 이어졌다.

## 핵심 한계

- 공개된 별도 참고사진이 없어 X 합성 이미지의 상단을 잘라 사용했다. 이미 색보정·크롭 또는 후처리가 적용됐을 수 있다.
- X의 구조와 스타일을 본 상태에서 프롬프트를 작성했으므로 블라인드 시험이 아니다. 강아지 사례는 공개 결과의 제목도 사용했다.
- 각 사례를 한 번만 생성했으며, 좋은 결과만 고르는 반복 생성은 없었지만 분산을 측정할 반복 횟수도 없다.
- 참고 이미지가 없는 대조군이 없어 참고 이미지 자체의 순효과는 계산할 수 없다.
- 세 표본 중 두 개가 같은 종이공예 계열이므로 다른 이미지 유형으로 일반화할 근거가 약하다.
- 생성 환경과 게시물 작성자가 사용한 환경이 같은지 확인할 수 없다. X 결과물의 별도 후처리 여부도 확인 불가다.
- 고정 70:30 평균은 필수 정체성 실패를 가릴 수 있다. 현재 스킬은 적용 항목만 재정규화하고 must-keep 실패를 별도 FAIL gate로 처리한다.

## 재사용 가능한 결론

이 관찰은 “특정 점수가 재현된다”는 근거가 아니라, 참고 이미지 작업에서 무엇을 명시적으로 통제해야 하는지를 찾은 제한적 진단 근거다. 시각 유사도는 생성 결과와 비교할 참고 또는 타깃 등 서로 다른 이미지가 두 개 이상 있을 때만 평가하며, 적용되지 않는 항목은 `N/A`로 제외하고 재정규화한다. 실제 결과는 참고 이미지 품질, 생성 모델의 이미지·문자 처리 능력, 합성 및 후처리에 크게 좌우된다.
