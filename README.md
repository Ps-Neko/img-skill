# img-skill

## What it does

짧은 아이디어를 이미지 생성 도구에 전달하기 좋은 구조화된 프롬프트로 바꿔 주는 Codex 스킬입니다. 요청이 구체적이면 추천 방향 하나를, 여러 해석이 가능한 요청이면 서로 뚜렷하게 다른 방향 네 가지를 제안합니다. 이 스킬 자체가 이미지를 만들거나 편집하지는 않습니다.

결과는 사용자가 쓴 언어를 따르며, 언어를 판단하기 어려우면 한국어로 작성됩니다. 특정 모델의 문법이 확인된 경우가 아니라면 프롬프트는 모델에 종속되지 않는 자연어로 작성됩니다.

## Important evidence boundary

이 프로젝트는 `@xiaoxiaodong01`의 공개 게시물에서 관찰한 패턴을 바탕으로 독립적으로 재구성한 것이며, 공식 도구도 계정 소유자가 보증하거나 승인한 방법도 아닙니다.

원본 프롬프트를 복사하는 대신, 공개 게시물에서 관찰한 패턴을 프로젝트 차원의 분석과 설계 원칙으로 일반화해 적용합니다. 관찰 근거와 해석, 근거가 적은 확장 제안은 서로 구분합니다. 자세한 방법론, 공개 근거 링크, 한계는 [한국어 연구 보고서](docs/research-report-ko.md)에서 확인할 수 있습니다. 이 보고서는 결과 품질이나 특정 이미지 모델의 동작을 보증하지 않습니다.

## Install in Codex

1. 아무 Codex 채팅이나 엽니다.
2. 아래 요청을 그대로 붙여 넣고 전송합니다.

```text
$skill-installer Install the img-skill skill from https://github.com/Ps-Neko/img-skill/tree/main/skills/img-skill
```

3. Codex가 설치 완료를 알릴 때까지 기다립니다. 스킬은 다음 대화 차례부터 사용할 수 있습니다. 화면에 나타나지 않으면 새 채팅을 시작하거나 Codex를 다시 시작하세요.

위 주소는 저장소 전체가 아니라 설치 가능한 `skills/img-skill` 폴더를 가리킵니다.

## Use in a new chat

첫 사용은 새 Codex 채팅에서 시험하세요. 아래처럼 입력합니다.

```text
$img-skill 제주도 작은 카페를 홍보하는 세로 포스터
```

한국어 설명 부분을 자신의 아이디어로 바꾸면 됩니다. 목적, 주제, 원하는 크기나 형태, 반드시 들어갈 정확한 문구, 색상, 유지할 요소, 나오면 안 되는 요소를 함께 적을수록 요청이 구체적이 됩니다. 이미지 안의 글자나 로고, 특정 모델의 제어 기능이 정확하게 재현된다고 보장하지는 않습니다.

## Input examples

- 여러 방향을 보고 싶은 포스터: `$img-skill 제주도 작은 카페를 홍보하는 세로 포스터`
- 구체적인 제품 광고: `$img-skill 검은 배경, 빨간 운동화, 4:5 광고, PULSE 01만 표기`
- 글자 없는 일러스트: `$img-skill 새벽 안개 속 소나무 숲, 가로 일러스트, 글자 없이`
- 참고 제품 사진 활용: `$img-skill 첨부한 머그컵 제품 사진을 참고해 정사각형 광고 프롬프트 작성. 컵의 형태와 파란 로고는 유지하고 배경만 따뜻한 주방으로 변경`

## Output behavior

목적, 주제, 형식, 분위기·스타일, 보존 요구사항 가운데 세 가지 이상이 빠진 요청은 여러 해석이 가능한 요청으로 보고, 의미 있게 구분되는 완성된 방향을 정확히 네 가지 제공합니다. 충분히 구체적인 요청에는 불필요하게 범위를 넓히지 않고 추천 방향 하나만 제공합니다.

각 방향에는 시각적 핵심 한 문장, 상세 프롬프트, 짧은 프롬프트, 정확히 세 가지의 수정 가능한 변수, 적용한 판단 근거가 포함됩니다. 네거티브 프롬프트는 실제로 도움이 될 때만 선택적으로 포함됩니다.

반드시 유지해야 하는 요구사항을 목적과 보조적인 스타일 선택보다 먼저 적용합니다. 요구사항이 충돌하면 충돌을 알리고 해결 방향을 제시합니다. 글자 없는 요청에는 임의의 글자, 숫자, 로고, 워터마크, 서명, 라벨이 생기지 않도록 명시합니다. 확인되지 않은 모델 문법은 지어내지 않고 `확인 불가`로 표시합니다.

## Update or remove

**업데이트:** 먼저 Codex에 로컬에 설치된 `img-skill`을 제거해 달라고 요청한 뒤, 위의 설치 요청을 그대로 다시 전송하세요. 설치 도구는 기존 스킬을 덮어쓰지 않고 의도적으로 중단합니다. 로컬 스킬의 위치를 모른다면 Codex에 기존 `img-skill`을 먼저 제거해 달라고 한 다음 같은 설치 요청을 다시 붙여 넣으면 됩니다.

**제거:** Codex에 사용자의 Codex 스킬 폴더에서 로컬에 설치된 `img-skill`만 제거해 달라고 요청하세요. 그런 다음 새 채팅을 시작하거나 Codex를 다시 시작하세요. 이 작업은 로컬 사본만 제거하며 공개 GitHub 저장소는 삭제하지 않습니다.
